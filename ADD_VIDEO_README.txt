ADD THE CASE VIDEOS TO THE HOME PAGE
1. Unzip. GitHub > Add file > Upload files. Drag in: Home.py and the media folder. Commit.
   (Home.py replaces the old one; the only change is a video section above the portal.)
2. Add your MP4 videos to the media folder on GitHub (Add file > Upload files, inside media/).
   Name each caption file like its video: rmti_liver.mp4 + rmti_liver.vtt, rmti_lung.mp4 + rmti_lung.vtt, rmti_breast.mp4 + rmti_breast.vtt.
   Files over 100 MB are rejected by GitHub; compress the videos first.
3. The video section appears only when at least one .mp4 is in media/, so the app keeps working before the videos are added.
4. If it does not update: Streamlit > Manage app > Reboot app.
UNDO: restore the previous Home.py.
