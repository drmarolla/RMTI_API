RMTI site update, build 2026-11-15 (navy, white and red)

1. Extract this zip (right-click, Extract all).
2. On GitHub open the repository main page, choose Add file > Upload files, select EVERYTHING inside the extracted folder
   (Ctrl+A) and drag it in. Folders pages, media and .streamlit land in the right places. Commit.
3. Streamlit Cloud: open share.streamlit.io, find the app, open its three-dot menu > Settings, set "Main file path" to
   Home.py and save. (The sidebar currently starts with "app.py": that means the old app is still the entry page.)
4. Manage app > Reboot app, then refresh the browser with Ctrl+F5.

How to tell it worked: the page at oncoclastics.streamlit.app opens on a navy menu bar with a looping showreel, and the footer
and the bottom of the Live 4D Lab, Liver Progression 4D and Live Risk Matrix pages say "Build 2026-11-15".
If you do not see that text, the old file is still in place.
