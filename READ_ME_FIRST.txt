MAKE THE PORTAL YOUR HOME PAGE
1. GitHub > Add file > Upload files. Drag in: Home.py, developer_portal.html and the pages folder. Commit.
2. In GitHub open pages/6_Developer_Portal.py, click the trash icon, Commit (the home page replaces it).
3. share.streamlit.io > your app > three dots > Settings > Main file path: change app.py.py to Home.py > Save.
4. Manage app > Reboot app. Reload the site.
UNDO: set the Main file path back to app.py.py.
