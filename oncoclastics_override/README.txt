OVERRIDE (one file)
1. Unzip. Open the unzipped folder. Drag ONLY the file  streamlit_app.py  into your GitHub repository root
   (github.com > your repo > Add file > Upload files). It replaces the current streamlit_app.py. Commit changes.
2. Optional, for matching slider colors: open .streamlit/config.toml on GitHub, pencil, select all,
   paste the text from PASTE_into_dot-streamlit_config.toml.txt, commit.
3. share.streamlit.io > your app > Manage app > Reboot app. (Main file path stays streamlit_app.py.)
4. Check: bottom of the left sidebar says "build 2026-11-22-e".
Undo: GitHub > streamlit_app.py > History > restore the previous version.
